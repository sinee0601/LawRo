# 평가 체계 구축과 분류 체계 v2.0.0

실행일 2026-09-29 · solar-pro2 · prompt p2 · taxonomy v2.0.0

## 한 줄 결론

사람 판정과 라벨러 간 일치도로 v1 분류 체계의 결함(조문의 주제와 성격이 한 라벨에 섞임)을 찾아 v2 로 고쳤다.
주제(primary) 정확도는 조문 표본에서 **88.3%** 로 쓸 만하지만, 새로 분리한 성격(`provision_type`)은 **61.7%** 로 아직 약하다.
v1 에서는 두 축이 섞여 어디가 약한지 보이지 않았는데, 분리하고 나서 약한 곳이 정확히 드러났다.

## 평가 체계

| 구성 | 내용 |
|---|---|
| 시드 분할 | dev 82 / test 79. 같은 질문의 번역본은 한쪽에만 둔다 |
| 조문 표본 | 무작위 60건. Claude 블라인드 라벨 → solar 와 다른 16건을 사람이 판정 (후보 출처·순서 숨김) |
| 라벨러 간 일치도 | 시드 30건(한·영)을 사람이 정답 없이 라벨링 → Cohen's kappa |
| 지표 | bootstrap 95% 신뢰구간, 대분류별 P/R/F1, macro-F1 |
| 오답 공개 범위 | dev 만. test·조문 표본의 오답 내용은 리포트에 표시하지 않는다 |
| 회귀 게이트 | CI 에서 API 호출 없이, 같은 test 항목의 정오 변화(부호 검정)와 정확도·macro-F1 하락폭으로 판단. taxonomy MAJOR 변경은 기준선 재설정을 요구 |

## v1 에서 드러난 것

| 근거 | 결과 | 조치 (v2) |
|---|---|---|
| 조문 표본 판정 | 블라인드 라벨과 solar 가 16/60 갈림. 11건이 META 대 주제 카테고리. 사람은 META 후보 14건 중 11건에서 주제를 고름 | META 삭제, 조문 성격을 `provision_type` 속성으로 분리 (D13) |
| 일치도: 여권 보관 | 사람이 한·영 2건 모두 강제근로로 라벨링 | 신분증 압수는 ILO 강제노동 지표 → MISTREATMENT.FORCED_LABOR (D14) |
| 일치도: intent | kappa 0.53 (가장 낮음), 모델도 dispute→info 9건 | 본문에 쓰인 사실(상대방 행위로 인한 불이익)로 재정의 (D15) |
| 조문 전수 추출 | 범위 밖 조문 0건 | §2 에만 있던 규칙을 §4 로 (R13) |

라벨러 간 일치도 (Claude 시드 라벨 vs 사람, n=30): primary 대분류 kappa 0.81, 세분류 0.65, 긴급도 0.64, 의도 0.53.
같은 시드에서 solar 와 Claude 라벨의 세분류 일치는 91% 로 사람(67%)보다 높다. 모델끼리 잘 맞는다고 정답은 아니다.

## v2 결과

### 시드 (test 79건)

| | v1 (p1) | v2 (p2) |
|---|---:|---:|
| primary 세분류 | 91.1% [84.8, 96.2] | 92.4% [86.1, 97.5] |
| macro-F1 (대분류) | 0.920 | 0.962 |
| intent | 0.776 | 0.828 |
| urgency | 0.793 | 0.845 |

두 열의 정답이 다르다(v1·v2 정답). 차이는 신뢰구간 안이라 개선이라고 말할 수 없다. v2 가 나빠지지 않았다는 정도로 읽는다.

### 조문 표본 (60건, v2 정답)

| 지표 | 값 |
|---|---:|
| primary 세분류 | **88.3%** (53/60) [80.0, 95.0] |
| macro-F1 (대분류) | 0.795 |
| provision_type | **61.7%** (37/60) |

provision_type 오답은 대부분 한 방향이다: administration→right_duty 13건, procedure→right_duty 7건.
모델은 기관이 할 일이나 절차를 정한 조문도 "권리·의무"로 보는 경향이 있다.

v2 정답은 v1 판정을 바탕으로 Claude 가 새 기준에 맞춰 다시 붙였다. 특히 provision_type 은 사람이 검수하지 않은 단일 라벨러 정답이다.

### 조문 전수 (1,307건)

| | v1 (p1) | v2 (p2) |
|---|---:|---:|
| 범위 밖 | 0 | 39 |
| 비용 | $0.209 | $0.233 |
| 처리 시간 | 33분 | 39분 |

- **범위 밖 0 → 39건**: 규칙을 §4 로 옮기자 적용됐다. 다만 출입국관리법 벌칙·통고처분(외국인 본인의 위반도 포함)과
  국민건강보험법 제105조(유사명칭)까지 범위 밖으로 가 **과잉 적용**이 보인다. R9-1 과 R13 의 우선순위를 명시해야 한다.
- **provision_type 분포**: right_duty 72%, administration 12%, general 6%, penalty 5%, procedure 5%.
  위 표본 결과를 보면 right_duty 가 과대 추정돼 있다. v1 에서 META 가 38% 였던 것과 비교하면 "답이 될 수 없는 조문"을 덜 거르고 있다.
- 비용이 늘어난 것은 가이드가 길어져(경계 사례·규칙 추가) 요청당 토큰이 약 6,500 으로 늘었기 때문이다.

## 한계

- 조문 표본은 test 성격이라 오답 내용을 보지 않았다. provision_type 을 고치려면 **조문용 dev 표본**이 따로 있어야 한다.
- 일치도 측정은 사람 1명, 30건이다. 법률 비전문가라 "가이드가 비전문가에게 통하는가"를 잰 것으로 읽어야 한다.
- LLM-as-a-judge 는 아직 만들지 않았다.
